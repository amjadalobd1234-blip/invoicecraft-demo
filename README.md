# InvoiceCraft

Professional invoice generator for freelancers.
Works 100% offline. No signup. No server.

## Features
- 3 invoice templates (Minimal, Classic, Modern)
- 7 color schemes + custom color picker
- PDF export
- Auto-save drafts
- Arabic + English (RTL/LTR)
- Install as phone app (PWA)
- Works offline after first load
- No signup, no tracking, 100% private

## Quick Start
1. Open `index.html` in any browser
2. Fill in your business info
3. Add your services
4. Click "Download PDF"

## Install as App
- **Android**: Chrome menu (⋮) → "Install app"
- **iPhone**: Share button → "Add to Home Screen"
- Works offline after installation

## Customization
- `style.css` — colors, fonts, layout
- `app.js` — logic and features
- `icon.svg` — replace with your logo
